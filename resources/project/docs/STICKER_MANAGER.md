# 手动管理表情包

连接微信并启动读取服务后，打开左侧「表情包」，也可以从「扩展 → 管理表情包」进入。

- **添加**：点击「添加表情包」，一次选择 1–20 张本地 GIF、PNG、JPG 或 WebP。每张最多 8 MB、边长最多 4096 像素，动图最多 64 帧，所有帧合计最多 8000 万像素。GIF 保留动画，其余格式转换为微信发送需要的 GIF。
- **编辑**：为表情填写准确的内容描述和最多 6 个标签。机器人根据这些描述与聊天内容选择图片。手动添加和编辑均不会调用模型。
- **删除**：点击卡片「删除」并再次确认。删除只影响当前账号池内副本，保留源文件与微信聊天记录。已开始发送的消息可能继续完成。
- **预览**：点击卡片图片查看完整表情，支持 GIF 动画。

手动添加与聊天收集共用当前账号的 50 张池子。相同图片合并，不重复占位。满池时手动添加会提示先删除，不自动覆盖；之后自动收集触发的 DS 满池评选仍可能替换池内表情。

手动添加的资源可用于当前账号的所有已允许聊天，即使关闭自动收集或「聊天来源共享」。聊天收集的资源仍按原来的来源、共享开关和聊天范围授权。每个聊天的表情发送开关仍生效；不同账号的资源不混用。

导入、编辑和删除立即保存，无需点击全局「保存设置」。账号或池内容在操作期间变化时，操作会中止并提示刷新，避免覆盖新内容。批量添加逐张处理，失败时显示每张的结果，已成功的图片保留；不会把图片导入任务提交到聊天会话或等待模型回复。

数据位于 `state/stickers/collected/<账号目录与账号标识的摘要>/`，索引为 `index.json`。手动删除会清除池内文件和引用，并让旧评选结果失效；短名单记录最近删除的 512 张图片，阻止它们被自动收集立即加回。再次手动导入可以恢复。

读取服务未启动时页面会提示启动；旧服务尚未加载此功能时，需要退出重开 WeChatAgent 并重启服务。安装包需重新构建后才能分发此功能。
