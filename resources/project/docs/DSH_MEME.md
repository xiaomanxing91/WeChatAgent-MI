# dsh-meme 图库与微信发送

WeChatAgent 使用原版 [dsh-meme](https://github.com/yyh-001/dsh-meme) 管理图库，在项目内部增加查询、素材准备和微信发送适配。无需修改或 fork dsh-meme；本次核对的上游接口来自 0.1.52。未来上游接口变化时，适配层会报告不可用，不会伪报已发送。

## 安装与启用

1. 在 DSH 侧栏打开“插件 → 添加插件”，输入 **dsh-meme**，按 DSH 的流程安装和启用。
2. 在 dsh-meme 的“设置 → 表情包”中启用需要使用的图库，并选择一个已启用的当前图库。网络收集的新素材会保存到它的当前图库。
3. 开发版更新代码后，先从托盘退出并重开 WeChatAgent，加载新控制台；再停止助手服务，在“工具”页准备项目配置，从托盘完整退出并重新打开 DSH，最后启动助手服务。dsh-meme 本身保持原版。
4. 在 WeChatAgent“扩展”页找到 dsh-meme 卡片，查看安装教程、复制插件名、检查连接，或进入“配置”。开启接入，逐个选择允许的好友/群聊；也可设置全局默认值，再为单个聊天覆盖。
5. 当前聊天的“表情发送”也必须开启。图库查询不需要联网搜索开关。

接入默认关闭，不会替你自动安装插件、启用聊天权限或发送测试消息。页面显示的聊天数是已保存配置；插件未检测到时会保留配置并明确显示未就绪。

## 本地图库搜索与发送

模型需要表情时，通过 `wechat_meme_search` 查询 dsh-meme 已启用图库，获取本轮候选，再用 `wechat_meme_select` 选择一张。适配器只接受当前轮次的候选，重新检查图库开关和当前聊天权限。

选中的图片经本机格式、大小和摘要校验，转换为现有发送器支持的 GIF，生成仅供当前账号、当前聊天使用的短时发送资源。桥接层使用资源 ID 发送，继续等待微信服务器回执；资源准备成功和微信已送达分别处理。dsh-meme 的网页 `[表情: 描述]` 标记不会直接作为微信消息发出。

本次发送与长期收藏分开处理：同时尝试加入共享表情池，池满时等待 DS 筛选，但不阻止当前图片发送；收藏失败或新素材未获保留也不撤销本次发送资源。短时授权约 10 分钟有效，最多缓存 16 张、合计 32 MiB，读取服务重启后失效，需要重新选图，不会作为额外共享图库提供给其他聊天。

活跃群聊中的一次回复可包含两段文字和一张表情，发送清单按顺序持久保存各项进度；新群消息不会覆盖尚未完成的配图。发送器忙碌时按短暂退避重试，最多重试 6 次、等待上限 30 秒；达到上限会记录过期原因并继续处理新消息。已经提交但未取得回执的表情只做最多两次回执核对，不重新上传或发送；仍未确认时明确保留未确认状态，避免重复刷图。服务重启后继续未完成项，不重发已确认的文字。

WeChatAgent 的微信会话使用自己的工具及人格约束，不开放原插件的 `send_meme` / `learn_meme` 作为微信发送入口，以免触发其 Web/QQ 通道。原插件在普通 DSH 会话中的功能保持原样；微信 preset 会过滤其全局陪伴提示，继续使用本项目的人设和最终回复协议。

## 自主联网补图

还需同时满足：

- 当前聊天已启用 dsh-meme 接入和原生表情发送；
- 在 dsh-meme 接入配置中开启“允许联网补图入库”；
- 当前聊天的联网搜索已开启，且本轮没有要求“不联网/不搜索”。

模型先检索本地图库，没有合适素材时，调用现有 DSH `web_search` 查找短公开关键词；再把本轮返回的来源 URL 传给 `wechat_meme_search` 的 `sourceUrl`，从实际网页的图片标签/元数据中提取候选。最后选图时受控下载，并调用 dsh-meme 原有识图接口核验内容后准备微信发送，同时尝试保存图库和共享收藏。图库保存失败不影响已核验的本次发送资源。

也可对本轮已授权的直接图片链接使用 `wechat_meme_import`。来自其他轮次、模型凭空编造或不在本轮来源中的链接不能用来补图。网页候选仅是线索，返回时标为尚未完成视觉核验；网站不可读、没有真实图片、图片下载/识别失败时，继续文字回复。

公网下载沿用本项目的 DNS/IP 校验、跳转检查、字节上限与取消信号。不会执行来源网页脚本，也不通过调低 TLS 校验来下载。联网素材先在本机生成有界 JPEG 预览，由原版 dsh-meme 对预览识图；入库和发送保留原始 GIF 动画，避免直接把 GIF 当模型图片请求提交。预览仍核验聊天绑定、大小和摘要。

网络搜索和新图识别可能消耗当前 DSH 模型额度；当前默认 DSH 模型需支持图片识别。识图失败不会把该独立调用的附件塞进微信聊天历史。

## 表情池和停用

入池继续沿用当前账号最多 **50 张** 的规则；满池的新素材进入待评选区，等待 DS 筛选，工具仍返回本次可发送的短时资源，并单独标记收藏正在等待筛选。是否收藏与实际微信回执分别处理，不需要在筛选结束后重新请求发送。已经入池的素材可按原有共享设置，在已允许聊天间使用。

被动收集聊天表情与主动导入图库素材分别授权：关闭“收集已允许聊天的表情”不影响单独开启的 dsh-meme 接入。关闭图库接入会阻止后续搜索和导入；已经通过校验并入池的素材保留，仍遵循表情池与发送开关。

## 排查

| 状态/错误 | 含义与处理 |
| --- | --- |
| 未检测到插件 / MEME_PLUGIN_UNAVAILABLE | 确认 DSH、本项目桥接插件、dsh-meme 均已启用，准备配置并完整重开 DSH |
| MEME_PLUGIN_INCOMPATIBLE | 上游 API 与适配契约不匹配，记录插件版本后检查兼容性 |
| MEME_LIBRARY_NOT_ALLOWED | 当前账号、聊天范围、接入开关或原生表情发送不允许此操作 |
| MEME_PACK_DISABLED / MEME_ACTIVE_PACK_DISABLED | 需要的图库已关闭，或当前入库目标未启用，在 dsh-meme 设置中调整 |
| MEME_SOURCE_NOT_IN_CURRENT_TURN | 使用了不属于本轮搜索/链接输入的网页或图片，重新搜索后再选择 |
| MEME_NETWORK_IMPORT_DISABLED | 联网补图或当前聊天联网未开启，或本轮明确禁止联网 |
| 收藏等待筛选 / review-pending | 共享池已满 50 张，等待 DS 评选；本次发送继续，实际送达仍看微信回执 |
| MEME_READER_UPDATE_REQUIRED | 读取服务仍运行旧代码，重新准备配置并重启助手服务后再试 |
| MEME_RECOGNITION_FAILED | 原插件未返回有效识图结果，核对 DSH 默认模型的图片能力 |

扩展页的安装教程只提供指引，安装仍交给 DSH 自己的插件管理界面。上游安装与 API 依据：[README](https://github.com/yyh-001/dsh-meme/blob/main/README.md)、[图库接口源码](https://github.com/yyh-001/dsh-meme/blob/main/index.js)。
