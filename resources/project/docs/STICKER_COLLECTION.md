# 统一表情池与联网搜索

## 好友和群聊共享表情池

同一微信账号的所有已允许好友和群聊共享一个表情池。仍尊重“聊天范围”；未允许的聊天、其他账号、普通图片和任意文件不会自动入池。

在“回复设置 → 原生表情发送”管理：

- **收集已允许聊天的表情**：默认开启。收到原生表情后后台准备与去重，无需机器人在来源聊天回复。前 50 张自动入池；池满时新素材进入待评选队列。
- **好友与群聊共享同一表情池**：默认开启。关闭后仅向当前聊天提供有本聊天来源的已入池表情。
- **学习并复用表情标签**：标签随正常看图学习，本地按对话优先匹配相关素材。
- **允许发送原生表情包**：发送仍可按聊天覆盖，关闭发送不停止收集。

池子最多 50 张不同素材。满池后由当前 DSH 项目配置的 DS 模型查看表情预览、标签和已确认使用情况，选择保留哪些素材；它可以用新候选替换旧表情，也可以拒绝全部新候选。不会自动按时间淘汰旧表情，不会让第 51 张未评选素材直接进入发送候选。

评选独立于聊天的人设与上下文，不向模型提供聊天原文、群名、好友昵称、CDN 凭据或本机路径，不执行插件工具或微信发送。每轮最多评选 8 个新候选，至少间隔一分钟；优先让正在进行的正常回复完成。评选会消耗当前模型额度，需要模型支持图片输入。DSH 未连接、模型不可用或结果格式无效时，保留当前池子，候选等待五分钟后重试。

界面显示已入池数量、待评选数量及 DS 状态。池和待评选数据保存在本机，不应上传至 GitHub。动态 GIF 保留动画；缺失本机资源时需开启“图片与表情包 → 允许从腾讯下载缺失的表情包”。这些腾讯下载与 DSH 网页搜索开关独立。

重启会保留池子。旧版超过 50 张的库保留迁移快照，先保持最多 50 张可用素材，其余保留为待 DS 逐批评选的旧素材，不直接删除。已经准备的素材不依赖最近图片索引，不扫描或重放未观察过的历史消息。

账号之间隔离。来源聊天被移出允许范围后，该来源不再用于共享；如果同一素材也有其他仍允许的来源，则仍可使用。发送前校验素材是否已入池、目标聊天、来源权限和文件摘要；已经提交的发送只继续查回执，避免重试重复发送。

## 启用联网搜索表情素材

1. 更新本项目源码后，在 WeChatAgent 的“工具”页准备配置；从托盘完整退出 DSH，再重新打开并启用当前项目插件。插件会注册 `meme-search` 技能和 `meme-search__search` 工具。
2. 在“聊天范围”或“会话”找到目标聊天，打开“会话设置 → 技能与工具”，分别勾选上述技能和工具，点击“保存此会话”。仅勾选技能不能执行搜索。
3. 在同一聊天的“会话设置”中将“联网搜索”设为开启；也可以继承已开启的全局联网默认值。
4. 向机器人发送“找个猫猫无语表情素材”或“找个熊猫鼓掌 GIF”。群聊使用“唤醒后回复”时，先 @ 机器人或使用唤醒词。模型也可按对话选择搜索，不需要提供网址。

本项目的表情素材搜索通过专用工具查询公开图片来源；与普通问题直接调用 DSH 网页搜索的通道不同。默认 `auto` 先尝试 Bing 图片元数据，失败后尝试 Openverse，也可在 DSH 项目插件的 `memeSearch.provider` 选择 `imgflip` 模板来源。每次最多三个候选，默认缓存 120 分钟，新查询间隔至少 20 秒，不需要另填搜索密钥。

搜索结果是素材链接，当前不会自动下载入库、添加微信收藏或原生发送。表情池也不是微信客户端的“收藏表情”列表。

如果技能或工具未出现，先确认 DSH 加载的是更新后的当前项目插件，再在会话窗口刷新清单。DSH 未连接、搜索来源不可用或本轮明确要求“不联网”时，搜索不会正常执行；工具会返回原因，不应把它当作开关未保存。

0.3.6 安装包已包含统一表情池、DS 评选模块与界面设置。首次应用需准备配置、完整重开 DSH 并重启助手服务；后续收集与共享开关保存后生效。
