# 单个聊天反复 NATIVE_SEND_REJECTED

旧版可能把一次被拒绝的文字发送保存在 `state/text-deliveries/`，同时持续保留该聊天的待发送任务。后续消息会反复重放这条失败记录，显示 `OneBot action failed: 1407 (NATIVE_SEND_REJECTED)`，但不一定真的再次调用微信发送接口。

修正后的行为：

- 明确被拒绝的文字任务结束，尚未发送的后续部分取消，队列释放。已经确认发送的部分保留，不重复发送。
- 新消息继续正常进入该聊天，不重新生成或补发旧失败回复。模型收到上一轮未发送成功的状态说明。
- 发送接口返回 HTTP 429 时，保存拒绝原因并按发送器忙碌进行有限重试；超时或次数耗尽后释放队列。
- HTTP 400、401、403、409，以及发送接口明确返回拒绝，保留具体原因和原生数字返回码（如有）。后续读取失败记录时继续返回原原因。
- 网络中断、HTTP 500 等发送结果未知的情况继续核对回执，不自动重新提交文字。

## 已卡住的设备

更新到包含修复的文件，停止再启动 WeChatAgent 助手服务。旧的 `rejected` 记录会在重放时终结对应失败任务；后续新消息可继续处理。服务重启不会自动更改微信账号、聊天范围或人格。

原有发送记录保留。旧记录未保存最初的错误原因时，只能标记为旧拒绝，无法补回之前的返回码。持续发生的新拒绝仍需要按日志排查微信状态或权限；本修复解决队列被一条失败任务长期占住的问题。

该修复与 DSH 会话的系统消息头错误分开。安装包需要重新构建后才包含修改，源码更新不会自动改变其他设备的安装文件。
