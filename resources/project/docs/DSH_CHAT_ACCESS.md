# DSH 技能、插件工具与群聊设置

技能和插件在 DSH 安装、更新和配置；WeChatAgent MI 保留微信账号、聊天范围、人设卡、回复方式以及每个聊天的能力授权。安装一个 DSH 技能不会自动向所有微信群开放。

## 首次应用这次修改

停止助手服务，在“工具”页准备配置，从托盘完整退出助手和 DSH，再重新打开并启动服务。旧的 DSH 会话和聊天历史保留，人设卡仍在 WeChatAgent MI 的“人格”页管理。

## 为不同聊天分配能力

1. 在 DSH 添加并启用技能或插件。
2. 在 WeChatAgent MI 的“聊天范围”加入允许的群聊或好友，保存聊天范围并重启服务。
3. 在“聊天范围”或“会话”找到对应聊天，点击“技能与工具”；也可打开“会话设置”后切换到该标签。
4. 分别勾选允许的技能和实际执行工具，点击“保存此会话”。可按名称、说明搜索，或只显示已选项。刷新清单会保留当前勾选。

保存只提交当前聊天的人格、回复方式、功能开关和能力分配，其他页面的草稿会保留。新增或移出聊天仍需使用底部“保存设置”。人格变更需要重启服务，其他会话设置在后续消息中应用。取消、关闭或按 Esc 时，未保存修改会提示继续编辑或放弃。配置冲突会保留当前选择并提示重新打开，不会静默覆盖。

技能提供任务说明，工具执行操作。只有技能、没有它需要的工具时，模型不能执行该操作。网页搜索和网页阅读继续使用现有功能开关；微信原生发送、主动聊天和上下文维护仍由 WeChatAgent MI 管理。

未授权的技能不会进入该聊天的技能清单；未授权的插件工具不会进入模型工具声明，也不能执行。每次调用仍经过 DSH 的原生工具执行与权限处理。当前不向群聊开放通用本机文件、命令执行、任务调度或全局配置管理工具。技能可以通过 `skill` 读取自身 `references/` 中的 md、txt、json 文档，不能借此读取目录外的文件或运行脚本。

DSH 全局插件的启停和后台行为继续由 DSH 管理；这里按聊天分配的是技能和插件提供的模型工具。第三方插件自身的数据策略由其实现决定。

## 不同群使用不同回复方式

在“聊天范围 → 群聊 → 会话设置”的“群聊回复方式”中选择：

- **继承默认**：使用“回复设置”的全局群聊方式。
- **自然参与**：普通群消息也进入回复判断，模型可以选择沉默。
- **唤醒后回复**：识别 @、唤醒词、引用本账号或拍一拍等现有唤醒信号后才进入回复判断。

各群独立设置，私聊规则保留。保存后对后续消息生效；切换为唤醒后回复时，尚未发送的自然参与回复会取消。已经提交的发送动作继续按原回执机制处理。

## 账号与迁移

技能授权、群聊回复方式和聊天人设映射按微信账号保存。切换账号后不会沿用上一个账号的群授权，切回时恢复对应设置。项目内置表情素材工具的缓存按账号与聊天隔离。

旧版通过 WeChatAgent MI 启用且已经授予联网和存储权限的表情素材搜索，会在准备配置时迁移为 DSH 的 `meme-search` 技能与 `meme-search__search` 工具授权，原允许的聊天范围保留。其他旧版自定义扩展不再由 WeChatAgent MI 加载，需要以 DSH 支持的格式在 DSH 安装；旧源码和数据不会自动删除。

DSH 暂未连接或插件未加载时，已保存的授权仍会显示，并标记“未加载”。离线时可以保留或取消已有分配；连接后在会话的“技能与工具”中刷新清单，可读取新安装的能力。

顶部状态表示机器人服务状态，可点击查看连接详情；“控制台已连接”不等于微信读取、消息桥接和模型连接都已就绪。

群聊表情收集与联网表情素材搜索的区别、开关和启用步骤，见 [表情收集与搜索](STICKER_COLLECTION.md)。
