# 群聊退群重进与身份恢复

群聊的数字 ID 现在按当前账号、真实 `chatroom` 标识持久保存，群名称只用于展示与搜索。改名、联系人名称变化及重新加入同一个真实群，不改变已保存的数字 ID。

升级首次读取时，可唯一确认的旧白名单绑定会继续使用原数字 ID。历史图片中明确的真实群关联也可用于恢复改名后的旧绑定。同名但真实标识不同的群分别保存，不自动继承有歧义的旧授权。

读取器定期更新联系人与会话资料；手动搜索会立即刷新。联系人库缺少群记录时，从微信会话库补齐群标识、群标题，不读取未允许群聊的消息正文。群名单中存在记录不等于已确认当前成员资格；实际发送仍由微信客户端校验。

如果旧群已无法自动匹配：

1. 在 WeChatAgent 打开的匹配微信中进入原来的群，确认手动收发正常并等待资料同步。
2. 在“聊天范围 → 群聊”找到原来的记录，点击“重新关联”。
3. 搜索旧群名或现在的群名，按群标识末尾确认原群，再点击“确认关联”。
4. 保留原来的聊天范围、人格、技能和 DSH 会话；需要时在会话页重新初始化即可，无须归档原会话。

已经绑定到另一个真实群的旧会话不会被静默转移；已经独立添加的两个群也不会被合并。如果进入的是重建后的另一个真实群，应作为新群添加。

绑定文件位于 `state/group-bindings/<账号范围哈希>.json`，不随公开安装包发布。读取器为唯一写入方，图片工作进程只读；写入有跨进程互斥及原子替换，损坏文件保留并报错，不覆盖旧记录。
