# 群友记忆

在“扩展 → 群友记忆”中开启或关闭功能，也可为单个已允许群聊覆盖默认开关。默认开启，仅在“聊天范围”中已允许的群聊生效，不读取私聊。更新代码后需要准备配置、完整重开 DSH 并重启助手服务。

群友按微信成员标识生成的完整摘要 ID 区分，昵称只用于展示。同名成员分开记录，改名会保留少量旧昵称。每个微信账号、每个群独立保存，其他群不会读取这份标签。

模型在正常回复过程中按需调用：

- `wechat_member_memory_read`：按成员 ID、昵称查询当前群的已观察信息。
- `wechat_member_memory_update`：引用本批当前成员的真实发言证据，记录互动倾向。

标签限定为“爱玩梗、表达简短、偏好详细解释、表达直接、语气温和、喜欢提问、乐于分享、喜欢接话、认真讨论”。它们是可修正的互动观察，不是心理诊断或固定性格结论。单条发言只形成“待观察”记录，至少三条独立证据后才标为已观察；重复使用同一句话不会增加可信度。转发、引用中的他人发言、拍一拍和未识别图片不用于性格证据，不记录健康、政治、年龄等推测。

JSON 路径为：

```text
<项目目录>/state/member-memory/<微信账号摘要>/<群聊ID>.json
```

文件保存成员 ID、当前与旧昵称、标签、证据引用及更新时间，不复制完整聊天原文。每群最多保留最近活跃的 500 名成员，每人最多 6 个标签；超过 90 天的标签证据会失效。少量互动不足时，模型应正常聊天，不强行给人贴标签。

示例结构（摘要已缩写）：

```json
{
  "version": 1,
  "accountScope": "账号摘要",
  "conversationKey": "wechat:group:123",
  "members": {
    "成员摘要": {
      "memberId": "成员摘要",
      "senderId": "456",
      "names": ["当前昵称", "以前的昵称"],
      "tags": [{"label": "表达简短", "status": "observed", "confidence": 0.55}]
    }
  }
}
```

关闭功能后停止新的记录和工具读取，已有 JSON 保留。需要手工调整数据时，先停止助手服务并退出 DSH，再备份对应文件；损坏或越界的文件会停止读写并保留原文件。记忆内容不能改变本机人设、群聊权限或执行规则，机器人不会在群内宣布存档或展示成员标签。
