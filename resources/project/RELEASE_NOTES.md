# WeChatAgent 0.3.7

## 新增功能

- **表情包管理**：新增独立管理页面，支持卡片预览、名称与标签搜索、内容描述编辑、删除二次确认；从扩展页也可直接进入。
- **手动添加表情包**：支持批量导入本地 GIF、PNG、JPG、WebP，一次最多 20 张、单张最多 8 MB；动图保留动画，重复图片自动合并。手动添加与聊天收集共用当前账号的 50 张表情池，满池时提示先删除，不直接覆盖已有表情。
- **群聊重新关联**：聊天范围中的已保存群聊新增“重新关联”入口，重新进群或群资料变化后，可核对真实群聊并恢复绑定，保留原人格、聊天设置和 DSH 会话映射。

## 修复问题

- **图片拖住整个会话**：为图片下载、解析、准备和模型请求增加明确的超时与失败处理。单张图片失败时改用可说明缺图的文字输入；失败或取消的图片不再反复进入后续模型请求，避免连续报错后只能归档重开。
- **表情发送阻塞后续消息**：文字回复与表情发送分别推进，表情超时、过期或明确失败后释放任务；已提交但结果未知的表情仅核对回执，避免重复发送。
- **退群重进后群聊搜索与会话异常**：群聊改用账号内的真实群 ID 保存绑定，结合联系人库和会话库补充资料，修复群名变化、同名群及联系人资料缺失造成的旧绑定失效。已确认的旧关联保留；无法确定的群需要手动重新关联，不合并不同群的历史。
- **DSH 历史加载失败**：修正规则说明写入顺序，避免缺少受保护的首条系统消息头；对该类已损坏历史保留备份并建立替代会话继续使用，旧上下文不会自动迁移。
- **群聊发送被拒后反复重试**：明确的原生发送拒绝会记录原因并结束该条任务，后续新消息继续处理；发送器忙碌有限重试，结果未知时继续查询回执。

## 优化内容

- **图片处理与发送队列**：限制并行处理量、等待时间、重试次数和待发送表情数量，隔离图片及表情任务，减少活跃群聊积压与迟到回复。
- **表情选择与管理**：手动填写的描述与标签可用于选图，无需额外模型调用；缩略图按账号缓存，搜索和刷新时减少重复图片处理。导入逐张显示结果，成功项保留；账号或表情池变化时提示刷新，防止旧页面覆盖新内容。
- **删除与评选一致性**：删除会同时清理池内资源和引用，使旧评选结果失效；最近删除的图片不会被自动收集立即加回，仍可手动重新导入。
- **更新与资料**：开发版与公开版版本号同步为 0.3.7，安装包包含表情管理、群聊关联、媒体恢复及使用说明。首次聊天范围为空，账号、读取凭据、聊天范围、人格编辑与私有状态在升级时保留。

升级前请停止助手服务，并从托盘完整退出 WeChatAgent、DSH 和匹配微信，再运行 WeChatAgent-Setup-0.3.7-x64.exe。安装后重新打开并启用当前项目 DSH 插件，再启动服务，以加载新的界面、读取器和模型插件。

表情包入口：左侧“表情包”或“扩展 → 管理表情包”。手动添加的表情供当前账号已允许的好友与群聊使用，每个聊天的发送开关仍生效；不同账号不混用。自动收集满池后的 DS 评选仍可能替换池内表情。删除不移除原始图片或微信聊天记录，已经开始发送的消息可能继续完成。

详见 [表情包管理](docs/STICKER_MANAGER.md)、[群聊重新关联](docs/GROUP_REJOIN.md)、[图片与表情恢复](docs/MEDIA_RECOVERY.md)。dsh-meme 仍需用户在 DSH 自行安装与启用。

适用 Windows 10/11 x64，匹配微信 4.1.10.27；包内 DSH 与插件 SDK 为 0.2.0-rc.2。安装器、SHA256SUMS.txt 与 VERIFICATION.json 作为 GitHub Release 附件发布。验证范围以 VERIFICATION.json 为准。
