# WeChatAgent MI 0.3.7

Windows 微信助手与独立桌面控制台。支持白名单好友／群聊、人格预设、独立 DSH 会话、天气查询、网页正文阅读、图片理解、原生语音发送、原生文字及表情包发送。内置功能可通过扩展页面管理。

## 安装使用

普通用户使用 GitHub Releases 附件中的 `WeChatAgent MI-Setup-0.3.7-x64.exe`。安装后通过“首次配置”登录自己的微信和 DSH、自动查找账号并连接验证数据库、选择聊天范围，日常操作无需命令行。首次白名单为空。安装器需由维护者上传至 Releases；本源码目录不包含它。

用户数据位于当前用户 AppData 下的 WeChatAgent MI 工作区。升级保留配置、人格编辑和私有状态；卸载保留用户数据。维护者的账号、密钥、联系人、聊天和运行日志未包含在源码中。

安装完成后，按“首次配置”依次连接微信账号、验证数据库、登录 DSH 并启用本项目插件、选择聊天范围，再启动助手服务。首次聊天范围为空，添加好友或群后保存并重启服务。

升级到 0.3.7 前，停止助手服务并从托盘完整退出匹配微信、助手和 DSH；安装后重新打开，确保加载新版界面与模型插件。账号、读取凭据、聊天范围、人格编辑及背景设置会保留。

## 版本与预设

- WeChatAgent MI：0.3.7；DSH 桌面端和插件 SDK 实际验收版本：`0.2.0-rc.2`。
- 匹配微信：Windows x64 `4.1.10.27`；版本可登录性需按实际账号和环境验证。
- 内置预设：傲娇助手、德克萨斯、洛奇希、示例助手、小鲸鱼。首次选中示例助手，可在桌面应用切换。
- 支持人格稳定复用、归档后创建新会话、图片完成后卸载输入、按聊天控制表情发送和标签缓存。
- 首次配置自动识别账号目录、获取并验证读取密钥，验证通过才安全保存；失败显示恢复步骤，保留原配置。
- 支持切换绑定账号：微信辅助进程不再误报为多客户端；读取凭据、聊天范围、消息状态与 DSH 会话按账号保存，切换后需完整重开 DSH。
- 支持人格 Markdown 导入、接收引用消息、按需联网搜索、逐聊天主动聊天与自动上下文压缩；联网及主动聊天默认关闭。
- 天气问题直接通过 DSH 网页搜索查询，缺少城市时先询问；气温、降雨和日期以实际返回的来源资料为准。
- 当前未提供主动拍回、文件发送、语音／视频理解或通用新版微信适配。

## 使用内置功能

技能与插件在 DSH 安装和管理，人设卡继续在 WeChatAgent MI 管理。在“聊天范围”或“会话”打开目标聊天的“会话设置”，独立选择人格、群聊回复方式、功能开关；切换到“技能与工具”读取 DSH 清单并分配能力。点击“保存此会话”只提交当前聊天，保留其他页面的草稿。具体步骤见 [DSH 技能与群聊授权](docs/DSH_CHAT_ACCESS.md)。


在“扩展”页管理微信功能开关并查看 DSH 能力概览；自主表情素材搜索在目标会话的“技能与工具”中授权。点击卡片查看详情，修改开关或适用聊天后保存。列表显示已开启、已关闭、部分开启及开启范围；详情逐个显示聊天状态和待保存反馈。扩展页与回复设置共用配置，DSH 未连接时仍能查看已保存的开关，实际功能需在服务连接后按条件运行。

| 功能 | 如何使用 | 默认状态 |
| --- | --- | --- |
| 网页阅读 | 在允许的聊天中发送“总结这个网页：链接” | 开启 |
| 联网搜索与天气 | 开启联网搜索后正常提问，模型结合前文按需检索，无需提供网址，例如“上海天气咋样”“最近这个有新消息吗” | 关闭；可为单个聊天覆盖 |
| 自主表情素材搜索 | 在 DSH 授权区域选择 meme-search 技能与 meme-search__search 工具，再发送“找个猫猫无语表情素材” | 关闭 |
| dsh-meme 图库接入 | 在 DSH 自行安装启用 dsh-meme，再在扩展页开启接入并选择聊天；联网补图需额外开启对应开关 | 关闭 |
| 群友记忆 | 按稳定成员 ID 记录有限互动标签，需要时由模型读取；每个账号和群独立保存 | 已允许群聊默认开启 |
| 原生表情发送 | 在允许的聊天中收到表情后，由模型按语境选择使用 | 开启；可为单个聊天覆盖 |
| 主动聊天 | 打开总开关，并逐个选择允许主动发送的聊天 | 关闭 |
| 自动上下文压缩 | 打开总开关，设置阈值和空闲等待时间 | 关闭；会话页另支持手动压缩 |

联网搜索现在由当前模型根据对话按需调用，沿用“扩展 → 联网搜索”的开关与聊天范围；不需要输入网址，也不要求固定搜索句式。模型会从追问中补全公开主题，普通闲聊不必检索。联网搜索直接调用 DSH 网页搜索服务，沿用当前账号和 DSH 搜索配置；天气、热点及普通事实检索使用同一通道。服务未就绪、登录失效、超时或无来源时说明对应原因，不切换其他搜索或天气接口。不必另外填写搜索密钥。本轮查到的来源链接可以交给网页阅读继续核实。仍受每轮 1–3 次检索、结果数、摘要长度和超时限制；仅查询公开关键词，临时说“不要联网”会取消该轮联网。未查到、搜索请求失败和网页正文读取失败会分别说明；已有来源摘要能够回答时，不强制再次读取正文。默认超时 20 秒，可设置 1–60 秒；已有 8 秒等较短配置会保留，可在回复设置调整为 20–30 秒。每次调用只请求 DSH 网页搜索，使用完整的已配置超时，DSH 服务内部检索由其自身设置控制。

网页阅读支持本轮用户提供的公开 HTTP(S) HTML 或纯文本页面，支持 gzip、deflate 和 Brotli 压缩响应。可以发送“总结这个网页：www.bilibili.com”，也可以直接发送网址；`www.bilibili.com`、`bilibili.com`、`b23.tv/…` 等省略协议的网址会自动补全 HTTPS。每轮最多三页、每页最多 12,000 字符。不登录、不执行页面 JavaScript，也不会自动访问正文中的其他链接。取得的页面文字会交给当前模型处理；Bilibili 首页可读取实际返回的推荐条目，视频链接只读取页面文字，不代表观看视频或读取未显示的字幕。登录页、验证码、浏览器提示页、纯动态页面、PDF 等无法读取时会说明原因。

如果提示代理 DNS 返回 Fake-IP，请在代理客户端将 DNS 模式改为 `redir-host`，或在其 `fake-ip-filter` 中加入目标域名（Bilibili 可加入 `+.bilibili.com`、`b23.tv`），再重启代理和助手服务。这是代理客户端的配置，助手不会自动修改系统网络设置；内网地址保护仍然有效。

0.3.7 安装包的网页阅读支持诛仙世界工具站行情页：通过该站固定公开报价接口读取女娲石和银两，按用户指定区服返回挂单、单位和更新时间；没有区服时先询问。网址后紧接“帮我看看”等中文请求也可识别。本版安装包已包含该修复。

### 给机器人补充表情

也可直接打开左侧“表情包”，批量选择本地图片添加、编辑描述和标签、预览动图或删除。详见 [表情包管理](docs/STICKER_MANAGER.md)。

1. 在“扩展 → 原生表情发送”或“聊天范围”中开启目标聊天的表情发送。
2. 在“回复设置”开启“学习并复用表情标签”；本机资源缺失时，可开启“允许从腾讯下载缺失的表情包”。
3. 助手运行后，由好友或群成员在这个允许的聊天中发送微信原生表情包。资源准备完成后，模型可在后续回复中选择使用。

0.3.7 安装包支持同一账号已允许好友与群聊共享统一表情池：后台准备、按内容去重、重启保留，按对话优先匹配标签。池容量最多 50 张，满池新候选由当前 DS 模型查看预览、标签和使用情况后决定替换或拒绝；模型不可用时保持原池。收集与共享开关和计数在“回复设置 → 原生表情发送”，发送仍按聊天控制；普通图片不自动入池，动态 GIF 保留动画。原有 meme-search 技能返回素材来源链接；另行启用 dsh-meme 接入后，可在当前聊天授权范围内核验、入库并发送图片。详见 [表情收集与搜索](docs/STICKER_COLLECTION.md)。本版安装包已包含表情池、DSH 按会话授权及配套技能模块。

### 自主表情素材搜索

项目提供的表情素材能力由 DSH 项目插件注册。在目标聊天的“会话设置 → 技能与工具”中选择 `meme-search` 技能和 `meme-search__search` 工具。同时开启该聊天的“联网搜索”，然后发送“找个猫猫无语表情素材”，模型也可按聊天语境使用；唤醒回复模式的群需先 @ 或使用唤醒词。

默认来源为 auto，保留候选缓存和查询间隔。工具返回未查看的素材链接，不会自动下载、入库或原生发送。配置在 DSH 项目插件中管理；微信原生表情发送继续在 WeChatAgent MI 管理。旧版已授权的聊天会在准备配置时迁移，详见 [DSH 技能与群聊授权](docs/DSH_CHAT_ACCESS.md)。

## 源码与构建

运行要求：Windows 10/11 x64、Node.js 22.13+（建议 24）、Python 3.10+ 及读取依赖。桌面构建依赖在根 package.json 固定版本。

```powershell
npm ci
npm ci --prefix packages/dsh-social-bridge-plugin
python -m pip install -r scripts/reader-requirements.txt
npm run desktop:build
```

构建完成后双击根目录 WeChatAgent MI.exe 或 WeChatAgent MI-Console.vbs。源码副本不包含微信、DSH、第三方 Hook、已编译原生库或任何运行环境，完整收发需独立准备相应组件。外部组件说明见 [发送后端](docs/WECHAT_HOOK.md)。源码模式的自动连接需另行准备已授权的 wx_key.dll，放到 components/weflow-cli/resources/key/win32/x64/；安装器会内置该组件，普通用户无需手动准备。

安装器构建需要已获授权的微信客户端、Hook 编译产物及 DSH 程序。准备到本机私有 state/hook 目录，设置 DSH 程序目录后构建；每次均校验 DSH 与 SDK 版本匹配，并按根 package.json 中的版本号生成安装器。

```powershell
$env:WECHATAGENT_DSH_SOURCE = '<DSH program directory>'
npm run desktop:build
npm run installer:runtime
npm run installer:build
```

## MI 版本新增：原生语音发送（相对 0.3.7）

> 本节为「WeChatAgent MI version」源码归档相较 0.3.7 发布说明新增的能力。运行期文件位于
> `scripts/` 与 `packages/dsh-social-bridge-plugin/`，随 `deployment.json` 一起落地到工作区。

- **能力**：模型可调用 `wechat_voice_send` 工具，把一段文字合成为微信**原生语音条**并发送，
  群聊与个人聊天均可用；语音在回复文字之后自动落地，判定以 reader 新增的 `localType=34` 行为准。
- **合成链路** `scripts/wechat_voice.py`：`edge-tts` 文本转语音 → `miniaudio` 解码为 24kHz 单声道
  SIGNED16 WAV → `pilk` 编码为 SILK_V3，落盘 `state/generated-voices/<sha256>.silk`。
- **原生发送** `scripts/native-hook/voice_sender.cpp`（`wechatagent_hook.cpp` 的 `/SendVoiceMsg` 路由）：
  微信语音载荷必须在 `#!SILK_V3` 魔数前补 `0x02` 字节（真实 UI 录音抓包格式），否则电脑端杂音、
  手机端无法播放。该修复已写入 `voice_sender.cpp`，由 `build-hook.ps1` 一并编译进 `version.dll`。
- **工具可见性**：`voice-gen.mjs` 通过 `VOICE_GEN_POLICY`（`Symbol.for('wechatagent.voice-gen.v1')`）
  注册到 `agentCtx`，并在 `social-tool-restrict.mjs` 的 `policies()` / `symbols` 中放行，否则模型看不到该工具
  （表现为“她说能调用但只发文字”）。
- **桥接**：`hook-onebot.mjs` 新增 `sendVoice`（白名单 `state/generated-voices/<64hex>.silk` + SILK 魔数校验），
  `qq-bridge` 的 `wechat-onebot-adapter` 以 `wechat_voice` 消息类型投递；`social-engine.js` 的 `#deliverVoices()`
  在回复后自动发送，并提供 orphan 兜底。
- **开关**：默认按聊天开关控制；`wechatagent.json` 的 `voiceGen` 配置可逐聊天覆盖。

注意：本节描述的是**语音发送**，不是语音/视频理解（接收侧）。0.3.7 关于“未提供语音／视频理解”的说明仍然成立。
